Desktop TTS console · PySide6

Text to speech, engineered like a studio.

Kokoro GUI is a dockable desktop console for turning text, or whole ebooks, into audio. Pick a named voice or clone one from a reference clip, run it through a live FX chain, and stream it back in real time.

The panels

Five docks, rearranged to how you work

The whole app is dockable Qt panels. Three ship with every engine, two appear only when the active engine actually supports them. No dead tabs, no engine-specific special-casing in the UI.

Always on

Generation

The core dock, schema-driven so it rebuilds itself per engine.

  • Language, voice, speed, split pattern
  • Output format & thread count
  • Segment caching toggle
  • Standard batch or real-time JIT mode
Always on

FX

Live audio post-processing, built on Pedalboard.

  • Reverb, Compressor, Low/High Shelf
  • Speed 0.5×–2.0×, volume, pitch
  • Normalize & silence trim
Always on

Lexicon

A pronunciation dictionary the engine consults before synthesis.

  • Case-insensitive literal overrides
  • Fixes acronyms, names, jargon
  • Compiled patterns are cached, not rebuilt per call
Engine-gated

Mixing

Blend existing named voices into a new one, with precise weighting.

  • Shown only when supports_voice_mixing
  • Saved mixes appear in the normal voice list
Engine-gated

Voice Reference

Clone a voice from a WAV instead of picking one off a list.

  • Shown only when supports_voice_cloning
  • Auto-transcribe via the bundled ASR model
  • Edit the transcript, save under a name

Generation modes

Batch it, or hear it as it's built

Standard

Text is split into chunks and rendered in parallel across a thread pool sized by num_threads. Fastest path for turning a whole file into one finished audiobook.

JIT (real-time)

A generation thread fills a playback queue while a second thread drains it with buffer management, so you start listening before the rest of the text has even finished rendering.

Everything else

The rest of the console

Multi-source input

Paste text, or load .txt, .pdf, or .epub. Turn a whole ebook into an audiobook.

Scripted multi-speaker

[Speaker:FX]: Text switches voice and FX mid-document, no re-running the app.

Smart splitting

Split by newline, paragraph, or sentence for better prosody at the seams.

SRT export

Subtitles generated in sync with actual segment durations.

Presets

Save and reload full configurations, FX chains included.

Intelligent caching

Segments are hashed and cached. Change a generation-affecting setting and it gets caught automatically.

Cross-platform audio

Playback runs on sounddevice/soundfile, not a Windows-only API.

UI customization

Adjustable interface scale, dark / light / system theme.

Get running

From clone to first sample in five commands

Terminal
# 1. clone
git clone https://github.com/CoffeeMethod/KokoroGUI.git
$ cd KokoroGUI

# 2. virtual environment
python -m venv .venv
$ .venv\Scripts\activate  # Windows
$ source .venv/bin/activate  # macOS / Linux

# 3. install
pip install -r requirements.txt

# 4. run
python main.py       # or run.bat on Windows

  • Python 3.11+

    The only hard language-version requirement.

  • eSpeak NG

    Needed for Kokoro's phonemization step.

  • A GPU is optional

    Both models run on CPU; PyTorch will use a GPU automatically if one's available.

  • First run downloads weights

    Both TTS models pull from Hugging Face the first time you select them.
