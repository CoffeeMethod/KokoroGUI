How it works

Four moves, and the text stays in charge

01 Write
Type, paste or import a .txt, .pdf, .epub or subtitle file. Or import a recording: Whisper writes its words into the transcript and each word stays tied to where it was said.
02 Assign
Select a line and give it a character. Or type [Marta]: in front of it. Each character has a voice, an engine and an FX, and its text is tinted in its color.
03 Generate
Press Generate and only the stale lines generate. Each clip is keyed by its text, voice, speed, language and engine version. Change one of those and the clip is stale. Change anything else and it isn't.
04 Mix
Play it, drag it, fade it, duck it, export it. FX, volume and pitch are applied when a clip plays, so moving a slider never costs a regenerate. Export writes one file, with subtitles and a cue sheet if you want them.

One project format, four kinds of work

Pick what you're making. The same transcript, timeline and .tbaw file handle all of them; what changes is which tools you reach for.

Features

Everything is a layer on the text

Voices, clips, takes, FX and word timings all hang off the transcript. Edit it however you like and the layers keep up.

Transcript

MSAD

Each run of text is tinted by its character. The gutter names the speaker when it changes and puts a play button beside every stale clip, so you can regenerate one line without touching the rest. During playback the spoken word lights up; Ctrl+click a word to jump there.

Transcript reference →

Timeline

MSAD

Clips follow the text in order with a pause between them, or sit where you drag them. When a regenerated clip comes back longer, the clips after it ripple. Markers, loops, timecode, and Shift+drag inside a clip to replace a few words with fresh speech.

Timeline reference →

Mixer

MSAD

Mute, solo, fader, pan, a volume automation lane and ducking on every track. Fades on every clip. Playback mixes in stereo in the audio callback, and export uses the same mixer, so what you hear is what you get.

Playback reference →

FX

MSAD

Seventeen Pedalboard effects, a convolution reverb among them, set for the project, a character or one clip. They're applied when a clip plays, so a slider move is heard on the next pass and never marks anything stale.

FX reference →

Characters

MSAD

A character is a name, a color, a voice, an engine and an FX. Keep them in a library every project shares, or local to one file. Kokoro and Audio8 characters can talk to each other in the same scene.

Characters reference →

Tags

MSAD

Type [Marta]: at the start of a line and the line is Marta's when you press Enter. [pause:1.5] puts a second and a half before the next clip. Auto-split turns a whole tagged transcript into clips in one go.

Tags guide →
Engines

Two local engines, picked per character

Each character chooses its engine in Edit > Characters, so a Kokoro narrator can introduce an Audio8 clone. The Settings and Voices tabs follow whichever character's clip you've selected.

The file

The format is named after the idea

.tbaw stands for text-based audio workflow. It's a zip with a manifest: the text, the clips, every generated segment, and the voices and presets the project uses.

  • Opens on another machine. Mixes, References, saved FX and impulse responses ride inside it.
  • Never half-written. Save runs in the background into a temp file and swaps it in. Autosave writes to a working copy, not your file.
  • Recovers after a crash. Reopen the project and it offers the unsaved session, even if the file was renamed or moved.
  • Small when you want it. Leave the generated audio out and the file is just text and settings; clips regenerate on open.

Install

From clone to first line

Python 3.11 or newer and eSpeak NG. Models download from Hugging Face the first time you use them.

4.0 is a beta. 4.0.0-beta.1 is the latest tag; drop --branch for the development branch and the unreleased changes. The aim is for every 4.x release to open a .tbaw from any earlier 4.x.

Looking for 3.2.0, the old one-text-box app? It's frozen. Clone it with --branch 3.2.0 and follow its own README. Only presets/ and custom_voices/ carry over.

Terminal
# clone the latest beta
git clone --branch 4.0.0-beta.1 --depth 1 https://github.com/CoffeeMethod/KokoroGUI.git
cd KokoroGUI

# virtual environment
python -m venv .venv
.venv\Scripts\activate       # Windows
source .venv/bin/activate    # macOS / Linux

# install and run
pip install -r requirements.txt
python main.py               # or run.bat on Windows
eSpeak NG
# Windows: run the installer from
https://github.com/espeak-ng/espeak-ng/releases

# macOS
brew install espeak-ng

# Debian / Ubuntu
sudo apt install espeak-ng

# Fedora
sudo dnf install espeak-ng

Python 3.11+

The only hard version requirement.

eSpeak NG

Kokoro needs it to turn text into phonemes. Install it before the first run.

A GPU is optional

Everything runs on the CPU. Options > Device picks CUDA when PyTorch finds one.

First use downloads models

Kokoro and Audio8 come from Hugging Face; Audio8 loads with trust_remote_code=True. Whisper is about 1.6 GB and asks before it downloads.

Smaller or offline transcription

Copy .env.example to .env. Set WHISPER_MODEL to small, base or tiny, or VOSK_MODEL_PATH to use Vosk.

Trouble with torch?

Follow pytorch.org for your OS and GPU before pip install -r requirements.txt.
