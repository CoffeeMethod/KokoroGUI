Desktop TTS console · PySide6

Text to speech, edited like a DAW project.

Kokoro GUI is a dockable desktop console for turning text, or whole ebooks, into audio. Assign characters to a transcript, watch clips land on their own timeline track, and generate only what's changed. Pick a named voice or clone one from a reference clip, run it through a live FX chain, and stream it back in real time.

FX

Live audio post-processing, built on Pedalboard: five groups, seventeen sliders. Non-destructive: applied when a clip is played or exported, never written into it, so a change is heard on the next play and no clip goes out of date.

  • Dynamics: Compressor, Limiter, Gain
  • EQ & Filters: shelf EQ, high-pass, low-pass
  • Spatial & Time: Reverb, Delay
  • Modulation: Chorus, Distortion, Phaser, Clipping, Bitcrush, GSM

How editing works

The document is the source of truth, audio is a render of it

Generated audio is never the primary thing you edit. The text is. Everything else, a clip's boundaries, its character, its cached audio, follows from that.

Document, Clip, Track, Character

A Clip is a range of the document's text plus a character and settings overrides. A Track is a lane a clip can be dragged onto, kept separate from Character so a clip can land on a track belonging to a different character than its own.

Dirty tracking

A clip is dirty whenever its text, character preset, or overrides no longer match what its cached audio was generated from. No manual "mark as changed" step, it falls out of the same content-hash comparison the segment cache already does.

Characters menu

Select a range in the transcript and reassign its character/FX directly. Coexists with the [Speaker:FX]: inline syntax as a faster typed alternative.

Auto-split

Turns a tagged script into clips automatically, one per tag (or one per paragraph within a tag, if you ask for the finer split) and generates them in one action.

Drag to reassign

Drop a clip on a different character's track to reassign it, with a confirmation prompt when the characters actually differ, or drop it on its own track to just move it.

Sub-range TTS replace

Drag inside a clip's waveform to carve out part of it and regenerate just that part under any character, with an editable transcript before it renders.

Undo/redo

Text edits and character reassignments both push onto a plain undo stack, reachable from the app's Edit menu or the standard OS shortcuts.

document.json

The whole project, text, clips, tracks, characters, autosaves here, separate from config_qt.json's app-level settings.

Generation modes

Batch it, or hear it as it's built

Standard

Text is split into chunks and rendered in parallel across a thread pool sized by num_threads. Fastest path for turning a whole file into one finished audiobook.

JIT (real-time)

A generation thread fills a playback queue while a second thread drains it with buffer management, so you start listening before the rest of the text has even finished rendering. Only available on engines that can generate faster than you can listen.

Everything else

The rest of the console

Multi-source input

Paste text, or load .txt, .pdf, or .epub. Turn a whole ebook into an audiobook.

Scripted multi-speaker

Smart splitting

Split by newline, paragraph, or sentence for better prosody at the seams.

SRT export

Subtitles generated in sync with actual segment durations.

Presets & characters

Save and reload full configurations, FX chains included. Existing presets migrate into reusable, color-coded characters on first load.

Intelligent caching

Segments are hashed and cached. Change a generation-affecting setting and it gets caught automatically.

Cross-platform audio

Playback runs on sounddevice/soundfile, not a Windows-only API.

Persistent layout

Dock positions and window geometry autosave to config_qt.json.

Get running

From clone to first sample in five commands

Terminal
# 1. clone
git clone https://github.com/CoffeeMethod/KokoroGUI.git
$ cd KokoroGUI

# 2. virtual environment
python -m venv .venv
$ .venv\Scripts\activate  # Windows
$ source .venv/bin/activate  # macOS / Linux

# 3. install
pip install -r requirements.txt

# 4. run
python main.py       # or run.bat on Windows

  • Python 3.11+

    The only hard language-version requirement.

  • eSpeak NG

    A system-level dependency Kokoro's phonemization step needs at runtime. Install it before your first run, see below.

  • A GPU is optional

    Both models run on CPU; PyTorch will use a GPU automatically if one's available.

  • First run downloads weights

    Both TTS models pull from Hugging Face the first time you select them.

Install eSpeak NG (system dependency)
# Windows: download the installer from the releases page and run it
https://github.com/espeak-ng/espeak-ng/releases

# macOS (Homebrew)
$ brew install espeak-ng

# Debian / Ubuntu
$ sudo apt install espeak-ng

# Fedora
$ sudo dnf install espeak-ng

# Arch
$ sudo pacman -S espeak-ng
