What every setting does

Every field in every panel, grouped the way the app groups them, with the parts the label doesn't tell you called out. Three are worth knowing first: the Settings tab edits whatever is selected, Audio8 ignores two of its own fields, and JIT streaming only exists for a project with no clips yet.

Options menuEngines, device, theme

Each character picks its engine, in the Settings tab's Engine row or in Edit > Characters, so one project can mix Kokoro and Audio8 voices; every engine a character uses stays loaded. The selected clip's character (or the first character, with nothing selected) decides what the Settings tab's fields look like and which editor the Voices tab opens on (Mixing for Kokoro, References for Audio8); the Voices tab's own Engine box opens another engine's editor without changing a character. Everything below is written per-engine where the two differ.

Language, the default voice, Parallel threads and an engine's own Model fields are kept per engine, so a Kokoro and an Audio8 character each generate with their own. An engine this install doesn't have shows as "(not installed)": its characters keep it, their clips play and don't generate. Without the kokoro package the app runs Audio8 and Dummy.

Options > Device picks CPU / CUDA / Auto for the Kokoro pipeline (the CUDA entry is greyed out when torch reports no device) and re-initializes the engine. Options > Theme switches between the dark (default) and light palettes. The three checkable entries under them are whether copying text carries its character and FX along, whether a paste splits off its own run, and JIT streaming for projects with no clips. The welcome dialog's "Show at startup" box is the one launch setting that isn't here; it lives on the dialog itself (File > Welcome…).

Transcript tabThe transcript

The transcript is a highlighting editor over the project's text, not a plain input field. Two combos sit above it: Character and FX, both reflecting the clip under the caret. Changing Character reassigns the selection (or the caret's whole clip, or its line for untagged text); changing FX sets a named FX override on the caret's clip, undoable like everything else. The left gutter names the speaker once per character/FX change (Narrator on one line, FX: Echo under it) and shows a small play button beside each stale clip that generates just that clip. Stale text is dash-underlined; a stale clip with a target duration whose text reads longer than the target gets a wavy amber or red underline instead (see Target (s) below). Thin rules mark clip boundaries and where Auto-split would cut. A music bed's line holds its file name and can't be edited; delete the whole line to remove the bed.

Every run of text is colored by its assigned character and FX, so the boundaries between speakers and effects are visible at a glance, without reading the inline [Speaker:FX]: syntax.

Selecting a range and opening the Characters menu reassigns that range's character/FX directly. Placing the caret inside an existing run instead shows that run's voice and FX in the Settings tab. Copying a range carries its character/FX metadata with it; pasting into a run belonging to a different character splits the paste into its own run rather than silently overwriting the destination's assignment, unless "character/FX paste splits" is turned off, in which case a paste inherits whatever it lands on.

Settings tabOne panel, three scopes

The top of the tab is built from the engine's own list of fields, and it edits whatever is selected:

Settings tab scopes
SelectionValues come fromEdits write to
Nothing selectedThe app's whole-document defaults, the shown engine's own for the per-engine fieldsApp settings (config_qt.json; per-engine fields under engines)
A clipIts character's settings, merged with its own overridesclip.overrides, never the app defaults
A characterThat character's settingsThe character directly, so every clip without its own override using it updates live

Only the fields below can vary per clip or character. Everything else (Language, Parallel threads, Enable segment cache, and any engine's own non-character fields like Audio8's sampling knobs) is shown disabled, not hidden, while a clip or character is selected, since those settings only make sense at the whole-document level.

Above the fields, the Engine row: with a character selected it sets that character's engine (refused while a job runs; the voice stays if the new engine has one by that name, else it becomes the new engine's default); with a clip selected it shows the clip's character's engine, greyed out; with nothing selected it is "Engine for new characters", the engine Add in Edit > Characters and subtitle import give a new character.

The fields below are what the two engines declare. Rows marked Audio8 only don't appear for a Kokoro character at all. Language, Voice (with nothing selected), Parallel threads and the Audio8-only rows are remembered per engine.

Voice & generation fields
SettingWhat it does
LanguageFor Kokoro, picks which phonemization pipeline runs; each language uses its own KPipeline and voice list. For Audio8 it's one of eleven labels from the model card. See the callout below: it currently isn't sent to the model at all.
VoiceKokoro: a named base voice (af_heart, bm_daniel, ...) or a saved Mix from the Voices tab. Audio8: a saved Reference (a WAV and its transcript) from the Voices tab.
SpeedKokoro: 0.5x-2.0x, passed straight to the pipeline as a native generation parameter. Audio8: shown in the same range, but see the callout below, it's currently not forwarded to the model either.
Target words per segment5-200, default 40. Text is generated in pieces of about this many words, one file and one subtitle cue each. A piece ends at the strongest enabled boundary between half and one and a half times the target; if there's none, it may run to twice the target to reach one. Only past that is a sentence cut, and never inside a word. Changing it marks the clips whose pieces move as stale.
Split at paragraphs / sentences / pausesWhich boundaries a piece may end at, strongest first: a blank line; a sentence end (. ! ? ..., not after Mr., Dr. or an initial); a pause (comma, semicolon, colon, dash, or a single line break). All on by default. Turning one off demotes its boundaries to the next level on, so with sentences off a full stop still counts as a pause.
Output formatwav, flac, mp3 or ogg, for whole-document generation in a project with no clips. Clips are always written in the project's bundle format (wav or flac, set in the Export dialog), and the exported file's format is chosen in Export.
Parallel threadsKokoro: 1-32. Each thread runs its own pipeline, so more threads generate more pieces at once. Audio8: 1-4, but one shared model generates one piece at a time, so more threads don't speed up the model itself.
Enable segment cacheFor whole-document and JIT generation: keeps each generated piece under cache/, keyed by a hash of what produced it, so a re-run with the same text and settings skips it. Clips don't need it: each clip's audio is written once into the project, under a name made from the same hash.
Cache reference encoding Audio8 onlyA second, separate cache that stores the model's encoded reference audio, keyed by the reference file's contents. Repeated segments against the same Reference skip re-running the audio encoder, independent of the segment cache above.
Max new tokens Audio8 onlyCaps how many tokens the model can generate per segment. Default 1024, hard-capped at 2048 to match the model's real max_seq_len; anything higher gets silently clamped by the model anyway.
Temperature Audio8 onlySampling temperature, default 0.8. Higher values add more variation between takes of the same text.
Top P / Top K Audio8 onlyNucleus and top-k sampling cutoffs, default 0.95 and 50. Standard token-sampling controls for the model's decoder.

Language and Speed do nothing on Audio8, currently. The model doesn't accept a language or speed at all, so the app never sends them. Audio8 takes the language from the reference clip and the text, and always speaks at its own pace. The two fields still show because the field list can't yet mark one as display-only. To change an Audio8 line's length, use Fit to slot, which time-stretches it on playback.

Settings tabProject and clip fields

Under Audio control, a group that changes with the selection: Project with nothing selected, Clip with a clip selected, hidden for a character. Every edit here is one undo step.

Project and clip fields
FieldScopeWhat it does
TitleProject (a subproject)The subproject's name: its line in the parent, its block and the breadcrumb show it. Stored in its own project.json.
Gap / Paragraph gapProjectSeconds of silence between clips placed one after another (default 0.35), and between clips with a blank line between them (default 0.9). 0 gives the old back-to-back placement. Clips you've dragged to a fixed time ignore both.

Track layoutProjectOne per character (default): a character gets a track the first time it's used. Unified, N lanes (3 by default): clips go on N shared lanes in text order, moving to the next lane whenever the speaker changes. Mute, solo, fader and pan then act per lane.
Timecode / Frame rate / Start / Drop-frameProjectShows the ruler and the transport clock as HH:MM:SS:FF. Start is the timecode of the project's first frame (broadcast material often starts at 01:00:00:00). Drop-frame applies at 29.97 and 59.94. Times inside the project stay in seconds.
Align locked clips to their first wordProjectA clip locked in time and placed at a fixed time starts early by the silence before its first word, so the word, not the breath before it, lands on the clip's time (a subtitle cue's in-time). The first word comes from the clip's word timings, else from the measured leading silence. Skipped for a clip with Trim Silence on. Until you change it, it's on in a project with any locked clip and off otherwise.
DuckingProject-40 to 0 dB, default -12. How far a track with its D header button on goes down while clips on tracks without D play. Playback and export duck the same way.
Source track / Source offset (s) / RemoveProjectThe original dialogue File > Import Source Track… copied into the project, marked "(missing)" when its file isn't there. Source offset is where the reference times start in the file: a track with a two-second leader has 2. Remove clears it (the copy stays, so Undo brings it back). The transport's Original and Both play it.
Gap beforeClipThis clip's own gap, over the project's. Blank uses the project's. A [pause:x] marker sets it when Auto-split creates the clip.
TakeClipSwitch between the clip's takes, like the timeline's Take menu.
Status / NoteClipReview state and a note, for the timeline filter and the cue sheet.
Source textClipThe original line a dub is written against. Press Edit to change it and Save to store it. It shows as the transcript gutter's tooltip, and a rough syllable count of both lines sits underneath (vowel groups per word: a length check, not a real syllable count).
Original (s)ClipThe part of the source track this clip dubs, as start - end in seconds. Subtitle import fills it from the cue's times; blank for none. The transport's Original and Both play that slice where the clip starts, even after you drag the clip.
Target (s)ClipHow long the clip should last, from its time on the timeline; subtitle import sets it to the cue's length. Blank for none. The timeline draws it as a slot, and Fit to slot aims at it.

Settings tabAudio control

Hand-coded, not schema-driven, so every engine gets the same fields here, still subject to the same three-scope rules above. These are the post-processing steps from the signal chain on the home page.

Audio control
SettingWhat it does
Volume0.1x-2.0x. A plain multiply on the waveform, applied second in the chain, after Trim and before Pitch.
Pitch (st)-12 to +12 semitones, shifted by resampling to a new length. This changes duration along with pitch, the classic "chipmunk" effect: raise the pitch and playback gets faster, lower it and playback gets slower. For pitch without a duration change, use the Audio FX tab's separate Pitch Shift effect instead.
FX Preset / ApplyLoads a saved FX into the Audio FX tab's sliders. The Apply checkbox is the master switch for the whole FX chain below; unchecked, none of the Audio FX tab's effects run even if individually enabled.
NormalizeScales the segment so its loudest peak sits at 98% of full scale. A simple peak normalize, not a loudness (LUFS) normalize. Runs last in the chain, after FX.
Trim silenceStrips leading and trailing audio below a fixed amplitude threshold. Runs first in the chain, before Volume.

TimelineTimeline

One track per character in use (or a few shared lanes, see Track layout) on a real seconds axis. Clips sit in text order across all tracks, 0.35 s apart (0.9 s across a blank line; both are Gap and Paragraph gap in the Settings tab with nothing selected, and a clip's Gap before overrides them): at their real duration once generated (with a waveform), at an estimated one before (dashed outline, no waveform; the estimate learns from generation_stats.json). A ruler runs across the top, a fixed header column names the tracks, and Ctrl+wheel zooms between 20 and 400 pixels per second.

TransportPlayback

Play / pause / stop, the position readout, the Dub / Original / Both switch and a Loop toggle, then Preview / Generate / Cancel, then one progress bar that carries the status text.

Transport
ControlWhat it does
Play / Pause / StopPlays the whole timeline through one stereo sounddevice output stream that mixes every clip at its timeline position with its track's fader, pan and automation and its own fades (overlaps are a plain sum, clipped to full scale). Position comes from the audio callback's frame counter, so the playhead is sample accurate. Space toggles playback anywhere except inside the text editor; Ctrl+Space toggles everywhere.
PlayheadA line across every lane plus a marker on the ruler. The transcript highlights the clip being played and scrolls to it without moving your caret. A clip that finishes generating mid-playback becomes audible without stopping.
Dub / Original / BothWhat playback plays. Dub is the project as it exports. Original plays the source track's slice under each clip that has an Original (s) range, and nothing else. Both plays the two together, each 6 dB down. Switching mid-play keeps the position. Greyed out on Dub while the project has no source track. The choice isn't saved with the project, and export is always the dub.
LoopWraps to the start instead of stopping at the end of the timeline. A loop region set on the ruler wraps inside that region instead.
Position readoutmm:ss.t, or HH:MM:SS:FF timecode when Settings (nothing selected) > Timecode is on, at the frame rate and start time set there. 29.97 and 59.94 can be drop-frame.
Word highlightWhile playing, the transcript underlines the word being spoken. Ctrl+click a word to jump there.
PreviewSpeaks the selected text (or the first 1000 characters of the document) with the project-scope settings, through the fire-and-forget preview player.

Video tabReference video

A tab beside Settings, for dubbing against picture. File > Load Video… fills it; Workspace > Simple hides it. The video plays muted: the transport is the only thing that makes sound, and the video never moves the transport.

Video
ControlWhat it does
PictureFollows the transport: play, pause, stop and seek. While playing, it's put back in step whenever it drifts more than 40 ms. Where video playback can't load on the machine (Qt's multimedia libraries missing), the tab says so instead, and the rest of the app works as usual.
OffsetThe video time at the timeline's 0, in seconds. Positive skips into the video, negative starts it later. Saved with the project.
Where the video livesThe project stores the video's path, relative to the .tbaw when both are on the same drive. When the file isn't there on open, the app asks you to find it. The Export dialog's "Bundle the reference video in the project file" puts a copy inside the .tbaw instead.

File menuProjects

A project is a .tbaw bundle (text based audio workflow): one zip with the text and clips, every generated segment, and the Mixes, References and saved FX it uses, so it opens on another machine with the same engines installed. The layout is on the format page. Older .json projects open and are converted next to the original. Launch reopens the last project you had open, then shows the welcome dialog over it.

Workspace menuWorkspaces & theme

Every panel is a dock. Drag one by its title to move it, drop it on another to stack them as tabs, or pull it out of the window to float it. Nothing about the layout is fixed.

Workspace > Advanced opens with the transcript and the Settings, Audio FX, Lexicon, Voices and Video tabs above the timeline and transport. Simple hides the timeline and the Video tab so the transcript gets the full height; the project and Generate behave the same. Each workspace remembers what you do to it and brings it back next time. Reset layout puts the active one back to its default. A project can also name the workspace it opens in.

Options > Theme switches between dark (the default) and light. The gutter, timeline and ruler use the same palette as the rest of the window.

Audio FX tabFX

Five groups, each section gated behind its own enable checkbox except EQ, which is always live (a slider left at 0 dB is simply a no-op), and Convolution Reverb, which is off while its impulse response is None. All of it runs through one Pedalboard chain together as step 5 of the signal chain. The whole chain (and volume, pitch, normalize, trim) is applied on playback and export over the clip's raw generated audio: edit anything here and the timeline plays the change, with no regeneration and no clip marked stale. The tab follows the selection: project defaults, a character's FX, or one clip's override, layered in that order.

Lexicon
SettingWhat it does
Original text / ReplacementA list of literal find-and-replace rules, applied case-insensitively to every segment's text before generation, on every path: clips, whole document, JIT and Preview. Adding or removing a rule marks the clips whose text it changes as stale, and no others. Useful for acronyms, names, or jargon a voice mispronounces.

Rules apply whichever character a line belongs to, whether it was assigned by hand or by a tag. A character can't have its own rules.

The Voices tab's Engine box, at the top of either editor, lists the engines that have one. It follows the selected character; pick another to edit that engine's voices without touching a character, and the next selection puts it back. A saved or deleted voice shows up in the Settings tab's and Edit > Characters' voice lists at once.

Files on diskPreset files

Saved FX are presets/fx/<name>.json, written by "Save FX Preset..." in the Audio FX tab. A project bundles the ones it uses under fx/, and its own copy wins over yours.

Character presets, presets/<name>.json, are from before characters existed. Nothing in the app writes them now. The first launch with the character library copies each one into characters/ and links matching characters in the open project. After that, only the whole-document path reads them, for [Name]: tags in a project with no clips.

Options menuJIT streaming

"JIT streaming (no-clips fallback only)" plays a project that has no clips yet while it's still generating: one thread fills a queue, another plays from it. That only works when the engine makes audio faster than it plays, with enough margin that playback never catches up.

Kokoro can. Audio8, one large model generating one piece at a time, can't, so with an Audio8 character selected the entry is greyed out and generation runs normally. Once a project has clips, Generate works clip by clip and the transport plays them, and this setting doesn't apply.
